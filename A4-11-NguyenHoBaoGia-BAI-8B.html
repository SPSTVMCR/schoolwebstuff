Biện luận số nghiệm phương trình bậc 2

Bài toán: Xác định số nghiệm của phương trình ax2 + bx + c = 0


B1: Xác định hệ số a, b, c của phương trình bậc hai: ax2 + bx + c = 0 (a ≠ 0)

B2: Tính delta = b2 - 4ac

B3: Kết luận:

  • Nếu delta < 0: phương trình vô nghiệm
  • Nếu delta = 0: phương trình có nghiệm duy nhất
  • Nếu delta > 0: phương trình có 2 nghiệm phân biệt
